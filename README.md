## Running the notebooks

1.  Clone or download this repository.
2.  Open the notebooks in Jupyter Notebook, JupyterLab, VS Code, or
    Google Colab.
3.  Install any required libraries if prompted.
4.  Some notebooks require their accompanying datasets (for example,
    `College.csv`).
